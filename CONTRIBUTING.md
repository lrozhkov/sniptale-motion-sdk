# Contributing

External code contributions are not accepted. Pull requests are not accepted. Do not prepare patches on the assumption that they will be reviewed or merged.

There is currently no public intake channel for feature proposals or general reports. Security information must not be posted publicly; follow [SECURITY.md](SECURITY.md).

Repository publication, if authorized later, does not change this policy. A change to contribution intake requires an explicit maintainer decision and an update to this file.
