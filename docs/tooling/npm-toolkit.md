# Sniptale Motion

Локальный комплект для создания и проверки декларативных эффектов Sniptale Effect v1. Промежуточный кандидат поддерживает создание, валидацию и Studio с отдельными ревизиями проекта. Browser proof, безопасное автообновление, экспорт через CLI и установка skill ещё не готовы. Пакет не опубликован; полный strict и платформенная приёмка ещё не завершены.

Нужны Node.js 22.12 или новее и npm. Установите полученный архив командой `npm install --global /полный/путь/sniptale-motion-0.1.0.tgz`. Репозиторий и инструменты разработки для работы не нужны. Установка не загружает браузер и не запускает lifecycle-скрипты пакета.

Выполните `sniptale-motion --help`, затем `sniptale-motion doctor`. Создайте рабочую папку командой `sniptale-motion init my-motion`, перейдите в неё и выполните `sniptale-motion new my-effect`. Эффект появится в `effects/my-effect/effect.sniptale-effect.json`. Проверьте его командой `sniptale-motion validate effects/my-effect/effect.sniptale-effect.json`.

Для целевого эффекта используйте `new my-effect --kind targetEffect`, для перехода — `--kind transition`. Относительные ассеты разрешаются от папки JSON; другой корень задаётся через `validate <файл> --asset-root <папка>`. Пути за пределами корня ассетов отклоняются. Статическая валидация не подтверждает рендер в браузере.

Команды `init` и `new` не заменяют существующие проекты и эффекты. При отказе записи команда завершается с ошибкой; частичная папка может остаться. Перед повтором проверьте её содержимое и выберите новую папку или идентификатор. Исходники пользователя автоматически не удаляются. Рабочая папка содержит `effects/`, `exports/` и `.tmp/`.

Опция `--json` возвращает один JSON-результат в stdout без прогресса. Коды завершения: 0 — успех, 1 — ошибка операции или невалидный эффект, 2 — неверные аргументы; остановка Studio сигналом возвращает 130 для SIGINT и 143 для SIGTERM. По умолчанию справка на русском; `--locale en` включает английскую справку. `sniptale-motion docs` показывает эту инструкцию; `--version` показывает установленную версию. В этой сборке doctor сообщает Node и платформу; поиск совместимого браузера для proof ещё не реализован.

Из рабочей папки выполните `sniptale-motion studio` или `sniptale-motion studio /путь/к/проекту`. CLI открывает установленный браузер и остаётся запущенным; Ctrl+C закрывает оба локальных сервера. `--no-open` выводит адрес без открытия браузера. `studio --no-open --json` выдаёт один JSON с адресами сессии, после чего ожидает остановки. Каждый запуск выделяет два свободных loopback-порта; адрес сессии действителен до остановки команды. Браузер при установке или запуске Studio не скачивается.

Studio читает документы `effects/<id>/effect.sniptale-effect.json` и ассеты внутри соответствующей папки эффекта. Идентификатор документа должен совпадать с именем папки эффекта. Невалидный эффект показывает диагностику и не добавляется в каталог. Доступ к каталогу требует токен из адреса текущей сессии; сервер не раздаёт рабочую папку целиком. Текущая версия загружает каталог при открытии страницы: после внешней записи откройте страницу заново. Для сохранения правок используйте меню «Сохранить ревизию проекта». Результат создаётся эксклюзивно под `effects/<id>/revisions/<uuid>/`, содержит самодостаточный Effect v1 JSON с ассетами и не заменяет исходник. «Ревизии проекта» позволяет явно принять сохранённую ревизию либо исходный документ для следующего открытия; текущий редактор при принятии не перезагружается. Выбор записывается в `effects/<id>/current-revision.json`: принятие ревизии сохраняет исходный документ, а выбор «Исходный документ» возвращает его в каталог. При активной ревизии внешняя запись исходника не меняет выбранную ревизию. Незавершённые или повреждённые ревизии не принимаются; после отказа незавершённая папка может остаться для проверки. Если ответ при сохранении потерян, проверьте список ревизий перед повтором. Автообновление ещё не реализовано. До появления этих команд переносимый документ можно получить существующим экспортом JSON в viewer; это отдельный файл загрузки, а не запись в исходник проекта.

For English help, run `sniptale-motion --help --locale en`. Install the supplied archive with `npm install --global /absolute/path/sniptale-motion-0.1.0.tgz`. Run `sniptale-motion init my-motion`, enter that directory, then run `sniptale-motion new my-effect` and `sniptale-motion validate effects/my-effect/effect.sniptale-effect.json`. Existing projects and effects are never replaced. Use `--json` for machine results. This intermediate build provides static validation; Run `sniptale-motion studio` inside the project to open its effects in your installed browser; use `--no-open` to print the session URL and Ctrl+C to stop both servers. Each session uses two separate loopback ports. The project directory is not exposed as a static web root. The catalog loads on page opening; Use the “Save project revision” menu to persist editable changes under `effects/<id>/revisions/<uuid>/`. “Project revisions” explicitly selects a revision or the original for the next opening. It retains the current editor contents and the original file. Incomplete or damaged revisions are not adopted. Live reload, browser proof, CLI export and skill installation are still pending.
