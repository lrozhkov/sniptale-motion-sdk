# Security

Sniptale Motion SDK is a public alpha preview. No version is currently covered by a long-term support commitment.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/lrozhkov/sniptale-motion-sdk/security/advisories/new). Do not disclose a suspected vulnerability through a public issue, pull request, discussion, or document. The maintainer will acknowledge a report within seven days. The maintainer will provide updates at least every fourteen days until resolution or closure.

The current threat model, enforced controls, trade-offs, and residual risks are documented in [docs/security/security-model.md](docs/security/security-model.md). This file owns reporting and support status. The security model owns technical analysis.
