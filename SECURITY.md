# Security

Sniptale Motion SDK is a public alpha preview. No version is currently covered by a long-term support commitment.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/lrozhkov/sniptale-motion-sdk/security/advisories/new). Do not disclose a suspected vulnerability through a public issue, pull request, discussion, or document. The maintainer will acknowledge a report within seven days and provide a status update at least every fourteen days until the report is resolved or closed.

The current threat model, enforced controls, trade-offs, and residual risks are documented in [docs/security/security-model.md](docs/security/security-model.md). This file owns reporting and support status; the security model owns technical analysis.
